## 已实现

- Python 标准库 Tk 三页桌面：档案、按本地日期裁切的时间线、集中 Review Queue；没有重写采集器。数据库和网络使用单独工作线程。
- 自然语言本地关键词建议、用户确认保存、项目/活动/软件/网站/说明编辑；建议不是大模型解析，项目仍需人工填写。
- 原始 interval/event 引用、最新有效 UIA/OCR 文本；过期、excluded 和没有截图均明确处理。无 URL 采集，不从正文猜 URL。
- 已批准组合规则、人工历史案例、可选模型、未知回退；模型只选候选任务，不生成事实时间、工具调用或新成果。
- 人工确认优先、修订链、撤销为可重算、忽略、不知道、私人化、删除；记住纠正默认不勾选。相似案例保持 tentative。
- 规则正条件、反例词、冲突、批准、禁用、编辑、删除；两次以上共同案例可建议规则，保存建议不等于批准。派生规则保留源片段引用，源案例修正/删除时撤销相应规则。
- 个人记忆导出和清空；导出不带原始正文。用户自行导出文件不在应用保留期自动清理范围内，删除记忆不会撤回外部副本。
- 文本 Provider 支持自定义 HTTPS 完整地址与模型；拒绝 URL 内凭据、查询参数及重定向。密钥只使用 Windows Credential Manager。单请求超时 15 秒，单批最多 100 片段、200 KB 输入、256 KiB 响应、2000 输出 token 上限、最多两次尝试；同 Provider 实例内精确请求缓存，仅保留校验后的 ID。
- 云端批次预览包含实际发送的档案、候选标签、标题与最多 2000 字正文；单批明确授权；默认零请求。云端仅在采集停止时运行，取消后拒收结果；已发送数据不能撤回。无后台自动模型调用。
- 数据库 v3 原子扩展；现有 v2 采集测试不自动升级。启用个性化后原采集器兼容 v3。7 天正文、90 天区间/修订；案例不复制正文。档案与主动批准的规则是持久配置，可手动删除；未批准的派生规则随证据到期清除。

## 已知限制与下一步

- F 阶段真实数据与全天性能验收尚未完成。当前为手动分析/复核 MVP，不提供自动全天模型调度。
- 当前 UI 为原生 Tk，未采用 React/TypeScript/Tailwind；桌面实际视觉验收尚待进行。
- 档案解析采用本地关键词建议；历史相似性采用保守词集合和内容匹配，中文语义、页面大幅变化、不同内容同任务等场景可能仍未知。没有概率校准，不显示虚构百分比。
- AI 只选择人工建立的候选任务；首次没有候选时需添加。仅实现 Chat Completions 兼容协议，真实厂商和具体模型的参数兼容性尚未验证。
- 无历史截图文件。附件的短期截图留存与 AGENTS 原图不落盘冲突尚未确认，故沿用原边界，文本纠正完整可用。
- 任务时间不做自动合并；未实现时间边界修改、每日总结和生产力评分。现有时区存储保留，日期显示使用当前系统本地时区。
- 大规模案例索引、真实模型质量评测、单条候选任务专用管理、自动识别调度属于后续优化；目前候选通过新建/纠正管理，清空个人记忆可删除全部候选。
